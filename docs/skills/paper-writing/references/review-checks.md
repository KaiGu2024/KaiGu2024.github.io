# Targeted review checks

Use the relevant check when requested or when a concrete source or terminology problem needs resolution. Scale the check to the passage and the consequence of an error.

## Claim-to-source check

Useful when drafting from raw outputs, reconciling conflicting numbers, or providing an explicit evidence audit. Ordinary editing can rely on the supplied manuscript unless there is reason to question a claim.

Trace the claims under review to their actual support: an output table or cell, code and associated output, data documentation, a paper's page or section, or another recoverable source. Use `file:line` when appropriate; code alone may establish a procedure without establishing its result. Check that value, unit, comparison, sample, and uncertainty agree with the claim.

Keep verified citations and bibliography keys. Resolve missing references through the available literature or the literature-review workflow when needed. Mark a gap rather than infer a missing number or source. Use `[TODO: number]` or `[CITE: handle]` in unfinished drafts when helpful; a clean-text edit can report unresolved issues outside the prose.

Keep working locators internal unless the requested deliverable includes provenance. For an audit, show the claim, source locator, and any discrepancy in a compact format suited to the task. A separate checklist is useful only when unresolved items need tracking.

## Terminology check

Start with the manuscript's cited or supplied literature. Compare definitions and scope, not just similar labels. Search further when the existing sources cannot settle a consequential naming question.

Retain a term that accurately names the intended construct. Correct inconsistent usage within the authorized scope; explain a substantive renaming with its supporting source. When traditions use incompatible definitions or the manuscript's intended meaning is unresolved, state the alternatives and what each would change. A deliberate new term needs a clear definition; failure to find an established term does not itself establish novelty.

Report the consequential choices, with a table only if several comparisons warrant one. This check supports naming consistency; the conceptual-framework section develops the underlying theory and literature synthesis.
